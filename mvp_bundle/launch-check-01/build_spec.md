# Build Spec — LaunchCheck v1 (`launch-check-01`)

## 1. Verified Buyer Problem
Indie founders and agencies routinely ship launches with broken links, missing OG/meta tags, or missing security headers because mainstream SEO suites (Ahrefs $29–$249/mo, Semrush $139–$299/mo, Moz Pro $49–$99/mo) are priced for enterprise marketing teams.

## 2. Architecture (100% Free Stack — $0/mo Fixed Cost)
- **Runtime:** Python 3.10+ stdlib only (`urllib.request`, `re`, `html`, `argparse`, `json`). Zero dependencies.
- **Outputs:** Dark-mode interactive `audit_report.html` grading SEO tags, OpenGraph previews, mobile viewport, alt attributes, placeholder links, and 6 security headers out of 100.
- **Pricing:** `$9` one-time Starter Fast-Win (1 sale = ~$8.10 net).
