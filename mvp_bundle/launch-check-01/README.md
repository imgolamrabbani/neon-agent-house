# LaunchCheck — Zero-Subscription Pre-Launch SEO, Link & Security Auditor

Catch broken placeholder links, missing meta/OG tags, and missing HTTP security headers in 5 seconds before your launch—without paying $49–$139/month for Ahrefs, Semrush, or Moz.

## Quickstart (3 Steps)
1. Audit any live URL or local `index.html`:
   ```bash
   python3 launch_check.py --target https://yourdomain.com --html audit_report.html
   ```
2. Open `audit_report.html` in your browser to see your 0–100 Launch Readiness Score and prioritized fix cards.
3. Verify anytime: `python3 launch_check.py --self-test`
