# Build Spec — ChangelogKit v1 (`git-changelog-kit-01`)

## 1. Verified Buyer Problem
Indie hackers and dev teams skip customer-facing release notes because manual writing is tedious and hosted changelog widgets (Canny $79–$99/mo, Beamer $49–$119/mo, LaunchNotes $249+/mo) charge recurring monthly SaaS fees just to display git updates.

## 2. Architecture (100% Free Stack — $0/mo Fixed Cost)
- **Runtime:** Python 3.10+ stdlib only (`subprocess`, `re`, `html`, `json`, `argparse`). Zero external dependencies.
- **Outputs:** Categorized `CHANGELOG.md` + searchable dark-mode static `changelog.html` drop-in for GitHub Pages / Vercel / Netlify ($0 hosting).
- **Pricing:** `$9` one-time Starter Fast-Win.
