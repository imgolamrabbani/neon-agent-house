# Build Spec — ScopeShield v1 (`scope-shield-01`)

## 1. Verified Buyer Problem
Freelancers routinely lose 20%–40% of project profit to casual "quick tweak" client DMs because they fear confrontation and don't want to pay $39–$65/user/mo for Proposify, Qwilr, or Bonsai just to issue clean Change Orders.

## 2. Architecture (100% Free Stack — $0/mo Fixed Cost)
- **Runtime:** Python 3.10+ stdlib only (`csv`, `json`, `html`, `urllib.parse`, `argparse`).
- **Outputs:** Printable dark-mode HTML Change Order (`change_order.html`) with Baseline vs. Scope-Creep KPI cards, itemized hours/delay/price table, and 1-click `mailto:` / clipboard polite client approval email.
- **Pricing:** `$9` one-time Starter Fast-Win (1 sale = ~$8.10 net).
